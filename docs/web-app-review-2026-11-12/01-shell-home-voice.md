# Shell, Home, Voice and cross-cutting design review

Reviewer scope: app shell (rail, top bar, shop switcher, bell, sign out), Home, Voice command, Notifications, Daily brief, Onboarding, and design-system consistency across all 26 screenshots. Screenshots are 1440px-wide captures, viewed downscaled. "(from code)" marks findings inferred from source and not seen in a screenshot.

## 1. Verdict

The shell is clean and on-brand, but the product does not yet feel voice-first or built for a busy counter. Voice is a modal you reach from two places only, it opens with focus on Close, and its first screen shows the wrong instruction. Home is a long stack of overlapping summaries. Low stock appears in four places, and the "shop desk" repeats the sidebar, while a streak counter takes the first slot above today's sales. Across pages the pieces were clearly built one at a time: there are five tab/filter patterns, four stat-row styles, four empty-state styles, text-only "Loading…" placeholders, a Refresh button on almost every page, and inconsistent kickers, back links, arrows and button icons. Fix the shared components first and most of the inconsistency goes away. Then make voice and "New sale" global and always one key away.

## 2. Top 5 changes

1. **Make voice and New sale global.** Put a mic button and one primary "New sale" in the top bar on every page, with keyboard shortcuts (for example `V` and `N`, and `/` for search). Remove the duplicate page-level New sale buttons.
2. **Rebuild the voice modal's first screen.** Put initial focus on a large mic button labelled "Tap to speak". Show 2–3 example phrases in the user's voice language and the active language. Remove the "Please verify the command" hint from step 1. Give each voice error its own message instead of the generic GST fallback.
3. **Turn Home into "Today + Act".** Order it as: today's sales hero, search/scan/voice, then one "Needs attention" list with inline actions. Merge the Stock watch, the attention grid and the alert count into that list. Delete the "shop desk" (it repeats the sidebar). Move the streak into a small badge.
4. **Ship one set of shared primitives:** `Tabs` (underline), `SegmentedControl` (2–3 options only), `FilterChips`, `StatRow`, `EmptyState`, a `Skeleton` that replaces the text `Spinner`, and a `PageHeader` with fixed rules for kickers and back links. Replace the per-page Refresh buttons with auto-refresh and an "Updated 1 min ago" line.
5. **Fix navigation reach.** Add Purchase orders, Cashbook, Estimates and Notifications to the rail (and a "More" tab on mobile). Collapse the shop card so Settings and Billing are visible on a ~730px-tall laptop screen. Make the shop switcher one control instead of the name shown twice.

## 4. System-level recommendations

1. **Tokens file.** Move colours out of literals into `:root` custom properties. Today shop.css has 66 raw `#ff6b00` plus at least six other saffron tints (`#ff9857`, `#ff9854`, `#ff8a33`, `#ff8b3d`, `#ff9148`, `#ff9a54`) and three greys used as "muted" (`#8a8a90`, `#aaa8b0`, `#a0a0a8`). Define `--saffron-500/400/300`, `--text-1/2/3`, `--line-1/2`, `--surface-0/1/2`, `--ok/warn/danger`. The `@theme` block also declares `--font-display: 'Space Grotesk'`, which `.shop-root` then overrides with DM Sans. Remove the dead value. Fixes S9, H9, D1 and colour drift.
2. **Type scale.** 12 (meta) / 13 (label) / 15 (body) / 17 (section) / 22 (card title) / 30 (page title) / 44–56 (hero number). Nothing below 12px. Labels in DM Sans 600 uppercase only for rail groups and kickers. Fixes H9, D1, D5.
3. **Spacing and radius.** Radii in use: 6, 8, 9, 10, 12, 16 and 24px. Use 3 values (8 controls, 12 cards, 20 sheets) and a 4px spacing grid with `--page-gap` 24/32. Fixes the boxy-vs-pill mix seen on Home desk tiles (6px) next to cards (12–16px).
4. **Component set in `ui.tsx`:** `PageHeader` (route-derived kicker, conditional back link, `updatedAt` meta, one primary action slot), `Tabs`, `SegmentedControl`, `FilterChips`, `StatRow`, `EmptyState`, `Skeleton`, `Toast` (with Undo), `Button` with a leading `icon` prop, `LinkArrow` (internal vs external). Fixes D1–D8, A1, A2, V6.
5. **Shell commands.** Add a `CommandBar` in the top bar: search, scan and mic, plus a keyboard layer (`/` search, `N` new sale, `V` voice, `B` scan, `?` shortcut sheet). This puts the three primary counter jobs on every page. Fixes S1, S2, S4, H3.
6. **Error mapping.** `Notice` should not fall back to GST copy for unknown codes. Use a per-domain map (`voice.*`, `sale.*`, `gst.*`) with a neutral default ("That didn't work. Try again."). Fixes V4 and probably similar leaks on other screens.
7. **Breakpoints.** Use three tokens (600 / 900 / 1200) and an icon-only rail between 900 and 1200. Fixes S10 and the cramped content area on 1024–1100px laptops.

## 5. Not checked

- Live behaviour: I did not run the app, so I did not check hover, focus order, animations, real latency, voice recording, mic-permission prompts, TTS playback, or the voice review/confirm screens (no screenshot exists past step 1).
- Phone and tablet widths: there are no screenshots below 1440px. Responsive findings come from CSS only.
- Onboarding, the trial banner, the offline banner, error states, and roles other than Owner (Manager/Helper navigation) were not captured in screenshots.
- Exact contrast was calculated for a few token pairs only (nav group labels, muted text, primary button, bell badge). The rest of the page was not audited with a tool.
- Screen-reader output, and translated (Hindi or other Indic) layouts with longer strings.
- Screenshots were viewed downscaled. Pixel sizes quoted come from CSS, not from measuring the images.
